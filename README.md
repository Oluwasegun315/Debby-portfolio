# Debby Tella website

## How to open the website

### Easiest
Double-click `START-WEBSITE.bat` in this folder.

Then open: **http://127.0.0.1:3000**

### From terminal
Use these exact commands (not `np`, and not only `start` without a build):

```bash
cd "C:\Users\DELL\Desktop\miss deborah website"
npm run build
npm run start
```

Or for development:

```bash
cd "C:\Users\DELL\Desktop\miss deborah website"
npm run dev
```

### Important
- Type **`npm`**, not `np`
- `npm run start` needs a build first (`npm run build`)
- Keep the terminal window open while browsing
- The real app folder is `debby-portfolio`
