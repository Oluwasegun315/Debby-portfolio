# Portfolio images

## Work spaces
- `social-media-design/` — Social Media Design
- `canva-template-design/` — Canva Template Design
- `powerpoint/` — PowerPoint
- `presentation-design/` — Presentation Design
- `ebook-cover-design/` — Ebook Cover Design

Wired in `data/work-categories.ts` and shown at `/work/[slug]`.

## Homepage feature rule
When a new workspace is added, the first **5** pieces automatically appear in the
homepage featured carousel via `getHomeFeaturedPieces()` / `HOME_FEATURE_COUNT`.
Full sets stay inside each workspace so buyers can browse more.
